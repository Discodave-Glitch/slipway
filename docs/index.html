Slipway

Find, check and install custom firmware on the M-VAVE FM-1.

Android or Chrome

Install firmware from your phone or a computer using Chrome. Includes the firmware list: pick a firmware, download it, and install it. Tested on one real Android phone (found the FM-1, downloaded and installed a custom firmware, and put the official firmware back).

  1. Use Chrome on the phone, a USB data cable (and a USB-OTG adapter if needed), and the official FM-1.fwsc from M-VAVE saved on the phone.
  2. Plug in the FM-1, switch it on, open Slipway Web and press Find my FM-1 (allow MIDI). For an app icon, use Chrome's menu → Add to Home screen.
  3. Choose the official FM-1.fwsc (step 2), pick a firmware from the list (step 3), then Install (step 4). Don't unplug while it writes.

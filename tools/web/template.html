Slipway

Firmware loader for the M-VAVE FM-1 · Android and Chrome

1 · Your FM-1

Not connected

Switch the FM-1 on and connect it with a USB data cable (a phone or tablet needs USB-OTG support), then press the button.

2 · Stock V15 (the way back)

The official V15 file is not saved yet.

Get FM-1.fwsc (the official V15: FM-1_015, 699,956 bytes. M-VAVE's site now offers only V16, which is not accepted here, so keep your V15 safe) from the M-VAVE downloads. It is checked byte for byte, and kept in this browser as your way back.

3 · Pick a firmware

Loading the firmware list…

The list comes from the public catalogue at thefirmwarehub.com. Every download is checked against the catalogue's checksum before it can be installed.

4 · Install

Firmware is made by the authors listed, not by Slipway. Read a firmware's own page for how to enter update mode and get back to stock.

Working

Starting…

Do not unplug anything. Keep this screen on and this tab open.Do not switch apps. The FM-1 stays in update mode until the write is finished.
Stuck? Rescue

An install was cut off: plug the FM-1 back in, press Find my FM-1, then choose the same file and press Install again. The FM-1 stays in update mode until the write finishes, and this finishes it.

The FM-1 shows a black screen and nothing responds: try another cable, then switch it off and on. If a computer lists it as WL82 UBOOT1.00 it can be recovered, but that needs a Windows or Linux PC. Use Slipway on the PC: Stuck? Rescue → Full recovery guide, or read it on GitHub.

The FM-1 is not found: use a data cable (not charge-only), plug the cable straight into the phone or tablet, close other MIDI apps, and allow the MIDI permission when Chrome asks (it must include SysEx).
